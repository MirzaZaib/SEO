# Interactive Technical Portfolio

A dark, static-first portfolio for Mirza Zaib, built for GitHub Pages with semantic HTML, CSS, and vanilla JavaScript. The site includes a responsive navigation, interactive canvas hero background, project showcase, research index, and client-side validated contact form.

## Run locally

Serve the repository root with any static server, for example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
