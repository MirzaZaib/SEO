🎓 Notes for Students: Why This Page Has Poor On-Page SEO

This box (and everything below it) is not part of the bad example — it's here to explain what's wrong above so you can compare it to the best-practice version of this same page.

  • No <meta charset> or <meta viewport>: hurts rendering and mobile usability, a Google ranking factor.
  • No lang attribute on <html>: hurts accessibility and language-based search targeting.
  • Generic, non-descriptive <title> ("Home"): ignores the primary keyword entirely and looks identical to millions of other pages.
  • No meta description: search engines will auto-generate a snippet, which is usually worse than a written one.
  • Multiple <h1> tags and skipped heading levels (h1 → h4 → h1 → h2): breaks the document outline used by screen readers and search engines.
  • Keyword stuffing: repeating "digital art" unnaturally instead of writing for humans — this can trigger a spam penalty.
  • Images with no alt text and no dimensions: inaccessible to screen readers, invisible to image search, and can cause layout shift.
  • Non-descriptive link text ("click here", "Page 2", "Stuff"): tells users and search engines nothing about the destination.
  • Deprecated HTML (<font>, <center>, table-based layout, bgcolor): not semantic, not responsive, and not maintainable.
  • Duplicate content: the same paragraph is repeated verbatim, which dilutes topical relevance.
  • No structured data, no canonical tag, no Open Graph tags: search engines and social platforms get no extra context about the page.
